关于 DeepSeek Harness 桌面端

DeepSeek Harness Desktop Gala 是 DeepSeek Harness（DSH） 的桌面客户端，面向 macOS 与 Windows。DeepSeek Harness 本身是 DeepSeek 开源的「万物皆插件」AI Agent 运行时，官方提供命令行与 Web 界面；这个桌面端把同一个运行时打包成可以双击启动的应用，并加入了官方没有的 Gala 角色皮肤系统——十位角色、各自可选开启的个性化人物与说话风格、整片舞台背景、一键换装，以及可选的角色独立空间。

它适合三类人：想直接用 DeepSeek Harness 而不想折腾 Node.js 和终端的用户；想给 DSH 换一套好看皮肤、让 AI 助手有形象的用户；以及希望在 DeepSeek-V4 上体验图片多模态对话的用户。安装包自带 Electron、Node 与固定版本的 DSH 运行时，API Key 在「设置 → 模型」填一次即可。

常见问题

DeepSeek Harness 有桌面版 / 客户端吗？

有。DeepSeek Harness Desktop Gala 是社区制作的 DSH 桌面客户端，提供 macOS（Apple Silicon）与 Windows x64 安装包，自带运行时，不需要安装 Node.js。

和官方 DeepSeek Harness 是什么关系？

基于开源的 DeepSeek Harness 构建，保留官方的 Agent、模型、工具、会话与插件生态，在此之上加入桌面壳与 Gala 角色皮肤。它是社区项目，不是 DeepSeek 官方产品。

DSH 皮肤 / 换肤是怎么做到的？

Gala 通过 DeepSeek Harness 的官方主题 token 与界面扩展点接入：选中角色后，侧边栏头像、欢迎页标题、整片对话舞台背景与配色一起换装；切回经典配色即可恢复。

怎么下载安装？

点击本页与你系统对应的下载按钮，或前往 GitHub Releases。macOS 下载 .dmg 拖入应用程序；Windows 运行 Setup.exe。Preview 未签名：macOS 首次打开到「系统设置 → 隐私与安全性」点「仍要打开」，Windows 在 SmartScreen 选「仍要运行」。

需要 DeepSeek API Key 吗？

需要。首次发送消息前在「设置 → 模型」填入，密钥只保存在本机；余额不足时界面会直接提示并给出充值入口。

支持图片输入吗？

支持。跟随 DeepSeek Harness 0.1.1，拖入图片并选择 DeepSeek-V4 Flash Vision 等视觉模型即可。

换了角色皮肤，AI 的回答方式会变吗？

开启「个性化人物」后会。十位官方角色各自带有专属人物设定：傲娇天才阿念、御姐大姐姐阿基、粘人管理员忆忆、星海巫女灵灵……开启后换上谁的皮肤，模型就用谁的语气回答；代码、命令与事实不受影响。该功能默认关闭，可在「设置 → 插件 → 角色空间」或换肤弹层一键开启；全员群星、经典配色与原装始终不带人物语气。

什么是角色独立空间？开启有什么代价？

默认关闭的硬核模式：开启后每个角色拥有自己的插件编队与非敏感设置，API Key、聊天记录与工作目录仍共享。代价是每次切换角色都会重启应用，首次进入某个角色会按当前公共配置生成它的工作台；启动失败会自动回到上一套可用配置。只想换皮肤的用户不需要开启。

DeepSeek Harness Desktop Gala (English)

A free, open-source desktop client for DeepSeek Harness (DSH) on macOS and Windows, featuring the Gala character-skin system: ten characters, each with its own opt-in persona and speaking style, full-stage backdrops and one-click dress-up on top of the official DeepSeek Harness runtime, with DeepSeek-V4 multimodal chat. Download the .dmg or Setup.exe above, enter your DeepSeek API key under Settings → Models, and start chatting. Community project, not an official DeepSeek product. Source on GitHub.

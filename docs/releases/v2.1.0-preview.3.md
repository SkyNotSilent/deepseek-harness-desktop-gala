# DeepSeek Harness Desktop Gala 2.1.0-preview.3

This Preview fixes the macOS crash that could occur as soon as a conversation used Bash to write or run code. It keeps the Preview update flow manual: the app opens this Release page and never installs a Preview automatically.

## What changed

- **Fixed the macOS code-tool crash** — the packaged `node-pty` loader now preserves an existing `app.asar.unpacked` path instead of appending `.unpacked` twice. Profile-shaped symlinks are covered by a real Bash PTY regression test.
- **Readable PTY failures** — a missing `spawn-helper` is detected in JavaScript before the native fork call, so the tool reports a useful error instead of causing a delayed native process trap.
- **Bundled Node and pnpm in code tasks** — Finder-launched sessions expose the app's own `node` and `pnpm` commands. macOS PATH recovery reads system path files and standard directories without executing `.zshrc`, `.zprofile`, `.bashrc`, or other user shell startup files.
- **Sandbox-safe package installs** — the bundled pnpm shim uses a private temporary store and cache, avoiding writes to user-global package-manager directories from workspace-limited tasks.
- **Local-only diagnostics** — bounded, redacted logs are written to `~/Library/Logs/DeepSeek Harness Desktop Gala/main.log`. Crash dumps remain local and are never uploaded automatically.
- **Stronger macOS release gate** — the Developer ID signed, Hardened Runtime-enabled, Apple-notarized DMG and ZIP are checked for identity, architecture, Gatekeeper acceptance, stapled tickets, updater metadata, quarantine behavior, and a real packaged PTY launch.

## First launch and update behavior

- **macOS:** drag the app into **Applications** and open it normally. The package is Developer ID signed and Apple-notarized; Intel Macs are not supported by this release.
- **Windows:** the Preview installer is not Authenticode-signed. In Microsoft Defender SmartScreen, choose **More info → Run anyway**.
- **Updates:** Preview builds notify you and open the GitHub Release page. They do not download or install an update automatically.

# DeepSeek Harness Desktop Gala 2.1.0-preview.1

The first public Preview of a character-first desktop experience for DeepSeek Harness.

## Highlights

- **Gala character stage** — the full ensemble and whale welcome you by default; switch to any of ten individual characters with her own palette, avatar, artwork and lines.
- **A real desktop Host** — Electron, Node and a pinned DeepSeek Harness runtime ship together for a zero-setup launch on macOS and Windows.
- **Multimodal chat** — image input and DeepSeek-V4 Flash Vision follow the bundled DeepSeek Harness 0.1.1 runtime.
- **Plugin-compatible workflow** — keep the upstream `dsh plugin` semantics, with a configured terminal available from the tray.
- **Desktop essentials** — system tray, profiles, bundled terminal and manual update checks.

## First launch

This public Preview is **unsigned**:

- **macOS:** open **System Settings → Privacy & Security** and choose **Open Anyway**. On macOS 14 and earlier, right-clicking the app and choosing **Open** also works.
- **Windows:** in Microsoft Defender SmartScreen, choose **More info → Run anyway**.

Preview builds use manual GitHub Release upgrades and never download or execute an update automatically.

## Quick start

1. Install and open DeepSeek Harness Desktop Gala.
2. Go to **Settings → Models** and enter your DeepSeek API key. It remains in the local DSH credentials file.
3. Open **Gala皮肤图鉴** from the sidebar and choose a character.
4. Start a conversation or drop in an image for multimodal chat.

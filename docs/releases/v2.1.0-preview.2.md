# DeepSeek Harness Desktop Gala 2.1.0-preview.2

> [!IMPORTANT]
> The macOS build can exit unexpectedly when a code task starts its packaged terminal. Upgrade to [2.1.0-preview.3](https://github.com/SkyNotSilent/deepseek-harness-desktop-gala/releases/tag/v2.1.0-preview.3), which fixes the packaged PTY path and has been re-signed and notarized.

This Preview turns Gala from a collection of themes into a persistent character layer with an explicit default IP, optional personas and isolated role workspaces.

## Highlights

- **GALA·群星 is the default IP** — the whale and ten-character constellation now appear on first launch, in both galleries, on the splash screen, in the app icon and across the download site.
- **Original really means original** — “恢复原装” removes Gala characters, backdrops, branding and colours. The choice persists across restarts and is no longer conflated with the default Stars skin.
- **Opt-in character personas** — ten official characters can answer in their own speaking styles without changing tools, code, commands or factual requirements. The composer prompt follows the active persona; the feature remains off by default.
- **Role workspaces** — an optional hard-mode switch gives each IP an isolated managed profile, plugin roster and non-sensitive settings. Credentials, conversations and working directories remain shared, and every workspace switch is validated before restart.
- **Persistent, readable stages** — character artwork remains behind both the welcome view and active conversations. Theme-aware masking and frosted message cards improve text contrast without flattening each character's palette.
- **Safer startup and rollback** — the splash screen follows the last healthy appearance, profile preparation is lazy and deterministic, and failed workspace boots return to the last-known-good profile.

## Migration notes

- Existing valid skin selections are preserved.
- A previously explicit `active: null` remains “original” after the skin store migrates to v2.
- A clean installation starts with GALA·群星.
- Role workspaces and character personas are both disabled until the user explicitly enables them.

## First launch

- **macOS:** drag the app into **Applications** and open it normally. The package is Developer ID signed and Apple-notarized.
- **Windows:** in Microsoft Defender SmartScreen, choose **More info → Run anyway**.

The signed macOS build asks before downloading an update and asks again before installing it. The unsigned Windows Preview only notifies you about new GitHub Releases.

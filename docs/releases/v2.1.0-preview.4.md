# DeepSeek Harness Desktop Gala 2.1.0-preview.4

This Preview fixes the sidebar **New Session** button when the current conversation is still blank, and tightens the signed macOS release gate. It retains the packaged PTY fix introduced in Preview.3.

## What changed

- **New Session works from a blank conversation** — clicking the plus button now creates and opens a genuinely new conversation instead of silently reopening the current blank session.
- **Signed DMG container** — the macOS disk image is signed in addition to the Developer ID signed, Hardened Runtime-enabled app inside it.
- **Real Gatekeeper verification** — release publishing now refuses to proceed when Gatekeeper assessments are disabled and requires `source=Notarized Developer ID` for both the DMG and extracted apps.
- **Safer notarization credentials** — Apple ID app-specific passwords are staged through a temporary Keychain profile over standard input and never placed in command-line arguments.
- **More reliable publishing** — interrupted draft uploads can be resumed safely, notarization waits have a bounded timeout, and macOS CI runs the desktop test suite before packaging.

## First launch and update behavior

- **macOS:** drag the app into **Applications** and open it normally. Intel Macs are not supported by this release.
- **Windows:** the Preview installer is not Authenticode-signed. In Microsoft Defender SmartScreen, choose **More info → Run anyway**.
- **Updates:** Preview builds notify you and open the GitHub Release page. They do not download or install an update automatically.

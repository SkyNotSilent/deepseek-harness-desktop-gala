# DeepSeek Harness Desktop Gala 2.2.0-preview.1

> Candidate release notes. This change set does not create a tag or publish a release.

## 中文

本候选版把桌面运行时升级并固定到官方 npm 发布的 DeepSeek Harness `0.1.2-alpha.2`。245 个公开运行时包以 registry 原始 tarball 固化，逐包记录 SHA-256、npm SHA-512 integrity 与许可证；`dsh-client-runtime`、`dsh-host-apiproxy` 已按上游拆分移除。

- 新会话按钮改用 alpha.2 的公开 session/workspace controller：当前空白会话下仍能连续创建不同会话，快速双击只创建一次，失败后可重试。
- 主窗口先在目标 Electron session 中用一次性 token 换取 HttpOnly cookie，再加载保留桌面 mode/platform 参数且不含 token 的页面；Gala 面板与主窗口共享该 session。桌面自有 renderer-boot 与全部 Gala HTTP 路由也经过同一 Host/Origin + cookie fence。
- Gala 和 Desktop 已迁移到 alpha.2 settings API；同时保留 `settingsNamespace`、`installSettingsSection`、`deepEqualJson` 兼容导出，避免旧插件仅因导出消失而阻断启动。
- 会话遥测与会话日志上传保持关闭。插件包名/版本清单按 alpha.2 默认随 DeepSeek 请求上报，不包含路径、配置、设置或凭据。
- WebFetch 完全跟随 alpha.2：默认 `standard`（以及 `ptc`、`cordis`）预设可用且不逐次审批，`minimal` 不启用；网络安全边界仍由上游执行。
- 会话数据按上游规则单向原地升级。升级后的记录可能无法被 `2.1.0-preview.4` 或更早版本读取；升级前如需保留降级可能，请先备份数据。

这是 alpha 运行时上的 Preview 候选，不是稳定版。正式稳定版至少等待 DSH 0.1.2 RC。

## English

This candidate upgrades and pins the desktop runtime to the official npm release of DeepSeek Harness `0.1.2-alpha.2`. All 245 public runtime packages are vendored as byte-identical registry tarballs with SHA-256, npm SHA-512 integrity and license metadata. The removed `dsh-client-runtime` and `dsh-host-apiproxy` packages are no longer referenced.

- New Session now uses the public alpha.2 session/workspace controllers. Repeated ordinary clicks create distinct sessions, rapid duplicates share one pending request, and failed creation can be retried.
- The main window exchanges its one-time token for an HttpOnly cookie in the target Electron session before loading a renderer URL that retains mode/platform parameters and contains no token. The Gala panel shares that session; Desktop-owned renderer-boot and Gala routes use the same Host/Origin + cookie fence.
- Desktop and Gala use the alpha.2 settings API while retaining the legacy `settingsNamespace`, `installSettingsSection`, and `deepEqualJson` exports for older plugins.
- Session telemetry and session-log upload remain disabled. The alpha.2 plugin inventory remains enabled: active plugin package names and versions accompany DeepSeek requests, but paths, configuration, settings, API keys, and credentials do not.
- WebFetch follows alpha.2 defaults: it is available without per-call approval in the default `standard` preset and in `ptc`/`cordis`; `minimal` does not enable it. Upstream network safety boundaries still apply.
- Session data is upgraded in place in the upstream, one-way direction. `2.1.0-preview.4` and older builds may not be able to read upgraded records; back up data before first launch if downgrade access matters.

This is a Preview candidate on an alpha runtime, not a stable release. A stable product release waits for at least a DSH 0.1.2 RC.
